 Web Du Lịch (ASP.NET MVC)

 Giới thiệu
Đây là website đặt tour du lịch được xây dựng bằng ASP.NET Core MVC.

 Chức năng chính
- Xem danh sách tour
- Xem chi tiết tour
- Đặt tour
- Xem lịch sử đặt tour
- Đăng ký / đăng nhập
- Gợi ý tour theo nhu cầu người dùng

---

Công nghệ sử dụng
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server

---

 Hướng dẫn chạy project

 1. Clone project
2. Mở bằng Visual Studio
3. Cập nhật database
Mở Package Manager Console: update database

Hoặc import database từ SQL Server.

4. Chạy project
Nhấn F5 để chạy.
